# Índice de aulas — linha de início no corpus

Mapa de cada aula para a linha exata em que começa dentro do arquivo `corpus_cof.txt` (ou equivalente). Gerado por varredura automática do corpus.

**Uso prático**: quando precisar consultar a aula N literalmente, use Read com `offset = linha_de_inicio` e um `limit` adequado (ex: 200-400 linhas para cobrir uma aula). Para encontrar trechos específicos dentro de uma aula, use Grep no corpus restringindo pelo range de linhas.

**Observações sobre o mapa**:
- O filename original diz "Aulas 1-293" mas o conteúdo vai até a Aula 472. A numeração do curso continuou.
- Algumas aulas no meio (ex: 70-76, 82-88, 90, 94, 102-103, 109, 115, 124, 128, 132, 135-146, etc.) não aparecem como marcadores "Aula XX" isolados no corpus — provavelmente OCR ou diagramação inconsistente. Essas aulas ainda estão no texto, mas sem cabeçalho claramente identificável; use busca por palavra-chave temática para localizá-las.
- Algumas numerações estão fora de ordem ou duplicadas (aparecem erros de OCR: "Aula 229" no meio da faixa 300+, "Aula 372" na faixa 326, "Aula 471" na faixa 370, "Aula 420" duplicada, "Aula 5" na faixa 460). Ao localizar uma aula pelo número, cruze com a data de início (primeira linha após o cabeçalho) para confirmar.
- Cada aula normalmente começa com o cabeçalho seguido da data (ex: "14 de março de 2009", "02 de abril de 2011"). A data ajuda a validar que você chegou à aula correta.
