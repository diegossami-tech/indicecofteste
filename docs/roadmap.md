# Roadmap

## Fase 1 - Base do projeto

- importar a skill original sem alterar o conteúdo;
- adicionar scripts de validação e empacotamento;
- documentar a estrutura e o fluxo de trabalho.

## Fase 2 - Higiene editorial

- verificar se os arquivos estão em UTF-8 consistente;
- corrigir caracteres corrompidos, se houver mojibake real nos arquivos;
- revisar títulos, descrições e instruções duplicadas.

## Fase 3 - Conteúdo

- completar os resumos pendentes em `indice-aulas-completo.md`;
- revisar o índice temático;
- separar fatos confirmados de hipóteses e aproximações.

## Fase 4 - Distribuição

- criar versão do pacote;
- definir changelog;
- preparar instruções de instalação específicas para cada ambiente de uso.
